# Repository instructions

Do not create, edit, or delete documentation unless the user explicitly asks for documentation changes. This includes README files and other documentation, even when code or configuration changes would normally call for updates.

When creating solutions, always keep in mind cross-compatibility for Linux, MacOS, and Windows. This project is meant to work natively on all platforms so that things like flashing don't need extensive configuration. In situations where making a cross-compatible solution causes very verbose scripts or logic, consider using a podman container.
